# Gate G1 — One-page research brief

**Student:** Farigh A. Sabri (MCL2026011), IIITA  ·  **Course:** AI Tools for Research, Lab 02
**Working title:** Can a citation be judged by how it looks? Measuring how much the surface form of a reference reveals about fabrication

| Field | Project information |
|---|---|
| **Review topic and key papers** | *Citation Formatting, Fabricated References, and Human Trust in AI-Assisted Scholarly Writing: An Interdisciplinary Review* (my review). Key papers cited in the review: Walters & Wilder 2023 (*Sci. Rep.* 13:14045); Ding et al. 2025 (AAAI 39); Ansari 2026 (arXiv:2602.05930); Metzger & Flanagin 2013 (*J. Pragmatics* 59). Found during the Lab 2 search (not cited in the review): Naser 2026 (arXiv:2603.03299). |
| **Research gap** | The review asked whether a more elaborate citation format raises readers' trust when existence and relevance are held constant, and found no study that isolates format. Part of its argument rests on the premise, drawn mainly from Walters & Wilder's 636 citations, that format carries no information about whether a reference exists; that premise has not been tested at scale. Two pieces of evidence pull in opposite directions: Walters & Wilder report that fabricated ChatGPT references followed APA style as closely as real ones, while Naser (found during the Lab 2 search) reports that a classifier using only the citation string reached AUC 0.876. If surface form is informative, the "trust the format" heuristic is partly justified; if not, it is miscalibrated. The human experiment itself needs participants and ethics approval, which this lab cannot provide, so I study the computational counterpart: how much a reader who sees only the surface of a reference *could* know. |
| **Research question** | **Primary:** How well can detectors that see only a citation's surface form (fields present, string shape, internal consistency, no database lookup) separate fabricated from real references? **RQ2:** Does that ability survive when real and fake references come from the same generator and share one format (Walters & Wilder ChatGPT citations)? **RQ3:** Which surface cues carry the signal, and what is left when formatting is equalised? |
| **Study pathway** | B (controlled comparative study) with an A component (reproduce the HALLMARK surface-feature control, then extend it to all hallucination types and a new evaluation set). |
| **Dataset / measurement setup** | HALLMARK v1.2.4 (MIT licence, GitHub `rpatrik96/hallmark`, pinned commit `c62d296`). Official splits `dev_public` (1,119; train/tune) and `test_public` (831; held out). External set: `supplement_chatgpt_citations` (341 ChatGPT journal citations human-coded by Walters & Wilder; 172 real / 169 hallucinated). |
| **Baseline / comparators** | B0 majority class; B1 completeness rule (a "format-trusting reader"); B2 HALLMARK's own surface-feature gradient-boosting control (code available, reproduced). Proposed: M1 extended surface features (same learner, one isolated change: added feature groups); M2 character n-gram logistic regression on the rendered citation text. Attributed reference points re-scored per entry: eight released zero-shot LLM verifiers on `test_public`; released bibtex-updater (database lookup) output on the W&W set. |
| **Primary metric and control** | AUROC on the held-out set (higher is better) with 1,000-sample bootstrap 95% CI. Secondary: detection rate (DR) and false-positive rate (FPR) at a threshold fixed on dev to FPR ≈ 0.10; MCC. Held constant: splits, features computed without lookups, learner settings, seeds 0–4. |
| **Computing and risks** | CPU only (2 cores, 7 GB); each full run takes minutes. Risk: no network access to Crossref/OpenAlex from the workspace, so lookup-based tools cannot be re-run (fallback: re-score released per-entry outputs, clearly attributed). Risk: benchmark artefacts (generator "tells") inflate surface detection; addressed by the W&W set and a format-equalisation test. |
